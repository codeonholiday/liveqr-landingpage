Cách lấy Euler Stream API key để kết nối TikTok Live

📅 Cập nhật 26/10/2026⏱ 4 phút đọc✍️ LiveQR

Euler Stream là dịch vụ hỗ trợ ứng dụng kết nối dữ liệu TikTok LIVE theo thời gian thực. API key của Euler giúp LiveQR TikTok xác thực kết nối để nhận bình luận, quà tặng, follow và các sự kiện live.

Đừng nhầm với stream key: Euler API key không phải RTMP stream key để phát video từ OBS lên TikTok. Đây là key dùng cho tính năng kết nối và đọc dữ liệu TikTok LIVE trong LiveQR TikTok.

Khi nào bạn cần key Euler riêng?

LiveQR TikTok có thể dùng cấu hình kết nối mặc định. Bạn nên tạo key Euler riêng khi app yêu cầu, cần quota kết nối riêng hoặc thường gặp tình trạng không thể kết nối do giới hạn lượt gọi. Key riêng giúp không phải dùng chung quota ẩn danh theo IP.

Tạo Euler Stream API key trong 4 bước

  1. Tạo tài khoản Euler StreamMở trang đăng ký Euler Stream, đăng ký bằng email hoặc phương thức đăng nhập được hỗ trợ. Xác minh email nếu hệ thống yêu cầu, rồi đăng nhập vào Dashboard.
  2. Mở Dashboard và tạo key mớiTrong Dashboard Euler Stream, tìm khu vực API Keys hoặc Sign API Keys, sau đó chọn tạo key mới. Đặt tên dễ nhận biết, ví dụ LiveQR TikTok.
  3. Sao chép API key ngaySao chép key vừa tạo và lưu tạm vào nơi riêng tư. Không gửi key cho bất kỳ ai, không đưa vào ảnh chụp màn hình hoặc Browser Source OBS. Nếu Dashboard chỉ hiển thị key một lần, hãy đảm bảo bạn đã copy trước khi đóng cửa sổ.
  4. Dán key vào LiveQR TikTokMở LiveQR TikTok, vào phần cài đặt kết nối TikTok LIVE hoặc Euler Stream, dán key vào ô Euler Stream API Key rồi lưu. Sau đó nhập username TikTok đang live và thử kết nối lại.

💡 Mẹo: Sau khi lưu key, chỉ kết nối lại một lần và chờ phản hồi. Việc bấm kết nối liên tục có thể nhanh chóng dùng hết giới hạn theo phút của dịch vụ.

Kiểm tra kết nối

  • Đảm bảo TikTok username nhập đúng, có thể kèm hoặc không kèm @ tùy ô nhập trong app.
  • Chỉ thử khi tài khoản TikTok đang thực sự LIVE.
  • Gửi một bình luận thử từ tài khoản khác và kiểm tra LiveQR TikTok đã nhận được chưa.
  • Nếu key vừa tạo, chờ một lát rồi thử lại vì cấu hình có thể cần thời gian đồng bộ.

Lỗi thường gặp

“Invalid API key” hoặc không xác thực được

Copy lại key từ Euler Dashboard, kiểm tra không bị thừa khoảng trắng khi dán và chắc chắn bạn đang dùng key còn hoạt động. Nếu nghi ngờ key bị lộ, hãy thu hồi key cũ và tạo key mới.

Không kết nối được dù key đúng

Kiểm tra username, trạng thái live và kết nối mạng. Euler Stream là một lớp kết nối trung gian; đôi lúc TikTok thay đổi hoặc máy chủ Euler quá tải, nên hãy cập nhật LiveQR TikTok và thử lại sau.

Gặp giới hạn kết nối

Không xóa/thêm lại phiên kết nối liên tục. Hãy đợi giới hạn theo phút hoặc giờ được reset, sau đó dùng API key riêng trong app để có quota dành cho tài khoản của bạn.

Bảo mật API key

API key giống mật khẩu của dịch vụ kết nối TikTok LIVE. Chỉ lưu trong LiveQR TikTok trên máy bạn; không đăng công khai, không gửi qua chat và không quay màn hình lúc key hiển thị. Nếu key từng xuất hiện trong ảnh hoặc video, hãy thu hồi key đó trong Euler Dashboard rồi tạo key mới.

  • Euler Stream Authentication — tài liệu quản lý Sign API keys.
