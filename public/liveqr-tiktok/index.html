Cài đặt nhanh

  1. Tải và cài app Chọn đúng bản macOS (Apple Silicon hoặc Intel) hoặc Windows ở khung bên trên. macOS: mở .dmg, kéo vào Applications. Windows: chạy file Setup.
  2. Kích hoạt license Mở tab License, dán key từ liveqr.me/licenses. Mỗi key gắn một máy.
  3. Kết nối TikTok Live Tab Kết nối — nhập username và thông tin phiên. Bắt đầu live trên TikTok, app tự bám stream.
  4. Dán overlay vào OBS Tab Overlay URL — copy link, thêm Browser Source trong OBS (hoặc Source Link trên TikTok Live Studio). Chỉnh vị trí máy in, đồng hồ trong app.
